# InkToLaTeX
Another neuroslop project. Plugin for MS WORD to convert the handwritten formulas and equations to LaTeX code. Works like a local server.
To start working with this project:
1. Change the paths in _start.bat where the folder inktolatex is located until ...\backend\... and ...\addin\... parts.
2. To work in Word create any folder and copy to it the \inktolatex\addin\manifest/xml
3. Open the folders properties->sharing->give access to (shield)->choose the user that will use this folder->give access-> copy the showned link
4. Open Word
5. Open settings -> centre of privacy and security-> settings of this centre-> secure catalogs of pluggins (addins)
6. Paste copied link
7. Add to catalogue-> Show in Menu
8. Restart the Word
9. Pluggins (Addins)-> another pld(addn)-> shared catalogs->choose the InkToLaTeX
that`s it you`ve installed that pluggin
